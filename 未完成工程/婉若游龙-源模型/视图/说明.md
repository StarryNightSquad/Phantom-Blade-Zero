## ⚠️ 这一版的网格是坏的，不要直接使用

渲染出来能直接看出来：**腿上是缠绕的布条，不是「龙纹网鞋」**，臀部裸露且大腿处有破洞。

原因在重建流程：

```
Dragon heels NSFW_p.pak
  → 它替换的是 WuCh_LTZ_Pants.uexp（整个下装的数据块）
  → 用 wcdump EXPORT 导出顶点 / 三角面 / 骨骼权重
  → 按骨名映射（明末骨名 → 游戏骨架 thigh/calf/foot/ball）
  → 在 Blender 里重建网格
```

问题出在最后两步之一：

1. **`wcdump EXPORT` 导出的索引可能错位**（导出的三角面与顶点列表不匹配 → 面被拉成条状）
2. **骨名映射覆盖不全**：有些顶点没有落到任何目标骨，或权重归一化后被截断，
   导致这些顶点在绑定姿势下被拉到别处

**正确的做法**应该是：不要自己重建网格，而是
**保留原版的 `WuCh_LTZ_Pants` uasset，只替换它的 `.uexp`（几何数据块）**——
这正是那个 mod 在明末里做的事。但这需要处理 uasset/uexp 的二进制结构，且只能在
明末那边（UE5.1 + 对应 usmap）做，跨引擎搬到 PBZ 不可行。

**替代方案**：在 Blender 里手工把布条状的几何删掉，只保留腿部皮肤，
再单独做一双网鞋模型接上去。工作量比重建整套小。
