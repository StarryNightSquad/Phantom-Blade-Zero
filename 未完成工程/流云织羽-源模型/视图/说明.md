# 视图说明

由 `tools/render_views.py` 渲染（Blender + Cycles CPU，正交相机，纯灰背景，三点光）。

| 文件 | 内容 |
|---|---|
| `_sheet.png` | 拼好的整张（四视图），1704×836 |
| `front.png` / `left.png` / `right.png` / `back.png` | 四视图单张，760×1500 |

**这一套用的是「黏土渲染」**：因为流云织羽的贴图从未导出过，所以按部位给了不同色调
（裙 / 上装 / 靴 / 护腕 / 羽毛 / 皮肤各一色），方便看清结构分区，不代表最终颜色。

T-pose 是 FBX 的绑定姿势，未摆姿。

- **手臂上有破洞**（前臂中段有暗色缺口）—— 该处网格面法线或材质槽有问题，需要检查

- 短发/马尾来自 `HaiKou_ShortHair_Head.fbx`
- 短裙是硬边几何（黏土渲染没有布料褶皱的贴图细节）
